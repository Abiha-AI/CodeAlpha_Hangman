# CodeAlpha Hangman Game — Task 1

Task 1 of the CodeAlpha Python Programming Internship.

A simple text-based Hangman game played in the console. The player is given 
a hint (the word starts with "R" and has 4 letters) and must guess the 
correct word within 6 attempts.

## How to Run

1. Make sure Python is installed on your system
2. Open a terminal in the project folder
3. Run:

   python CodeAlpha_Hungman.py

## How to Play

- The program asks you to guess the word
- You have a maximum of 6 wrong attempts
- After each wrong guess, it tells you how many attempts remain
- Guess the word correctly before running out of attempts to win!

## Key Concepts Used

- Python basics (variables, input/output)
- `while` loops
- `if-else` conditional statements
- Set data structure
- String methods (`strip()`, `title()`)
